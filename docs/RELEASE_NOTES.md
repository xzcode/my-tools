# My Tools 0.6.0

- 所有 20 项工具使用统一多标签工作台，可重命名、拖动排序、复制非敏感配置、关闭、恢复。
- 关闭与运行历史，逐条恢复/删除，按当前或全部工具清理 7/30/90 天以前、指定日期之前或全部历史；打开标签不受影响。
- 默认仅持久化非敏感配置，明确开启后按字段加密保存完整会话，支持旧 AES 工作台存档迁移；完整存档上限 32 MiB。
- 国际手机号校验：默认 +86，国旗和可搜索区号，多行号码规划校验、E.164 与类型。
- 本地 SVGA 1.x/2.x 预览：画布、动画参数、播放/暂停、停止、循环、帧进度及背景。5 MiB 输入、32 MiB 解压限制；无音频支持。
- 保留 AES 精确字面量密文前缀、Java ECB 兼容、GCM/CBC 及模板。

实际安装包以本次 GitHub Actions 结果为准。macOS 默认 ad-hoc 签名、Windows 未商业签名，自动更新默认关闭。
