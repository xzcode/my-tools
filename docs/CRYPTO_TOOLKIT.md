# 通用密码学工具箱 · V2 实施规格

本模块进入 My Tools，而非 Shell EX SSH 工作台。所有运算使用本机 Web Crypto / Worker；没有支付宝、微信或其他支付平台专用预设。保留原 AES 格式、密文前缀与 Java ECB 兼容。

## 当前开发批次

| 阶段 | 本批实现范围 |
| --- | --- |
| M0 | 通用密码学分类、统一工具目录/Worker、密钥格式及敏感历史规范 |
| M1 | RSA 2048/3072/4096、ECDSA/ECDH P-256/P-384/P-521、Ed25519、X25519（取决于 WebView）；命名公私钥；同一密钥对输出 PEM/DER/Base64 DER，RSA PKCS1 与 PKCS8/SPKI；默认路径保存、目录选择、显式导出、同名不覆盖 |
| M2 | 密钥匹配、解析、SPKI 公钥提取、RSA PKCS1 转换、DER 文件导入、SHA-256 公钥指纹 |
| M3 | RSA PKCS1 SHA1/256/384/512、PSS SHA256/384/512（Salt 长度）、ECDSA SHA256/384/512（DER/P1363）、Ed25519 签名验签；UTF-8/Hex/Base64 字节输入 |
| M4（部分） | Query/Form 报文排序、筛选、空值/重复键、解码、拼接，显式带入通用签名工具。JSON 原始字段提取另行实现 |
| M5（部分） | RSA-OAEP SHA1/256/384/512、Label、长度检查，不自动分块 |
| M7（部分） | SHA-384、SHA-1 兼容摘要与 HMAC |
| M8（部分） | ECDH/X25519 原始共享秘密；需另行使用 KDF |

密钥文件目录采用 name_algorithm，同名追加时间后缀。默认 Documents/My Tools/Keys（Documents 不可用则用户主目录）；用户通过本机目录选择器修改，写入独立配置并立即持久化。配置损坏时提示重新选择，而非重置。保存需要用户显式确认。Unix 文件夹 0700、文件 0600；Windows 使用所选目录的继承权限，私钥未加密。浏览器预览只能导出 ZIP，不能设置本地目录。

## 安全边界

新密钥工具不将输入、私钥、输出放入普通历史或任何工作台持久化，即使用户此前启用了完整会话保存；仅保留非内容参数与标签元数据。不会联网、自动生成新密钥覆盖已有文件，也不会自动上传。运行时密钥仍存在内存中，不能承诺内存级安全擦除。遗留 SHA-1 仅为兼容。ASN.1 转换仅处理格式封装，密码运算由 Web Crypto 实现。

## 后续阶段（未实现）

SM2/SM3/SM4、更多摘要与对称算法、SHA-224/SHA3/RSA-PSS 独立 MGF、GBK 等字符集、Ed448/X448/DSA、SEC1/PKCS12/JWK/OpenSSH、加密私钥、证书/CSR、密钥管理目录索引与历史、JSON 原始报文提取、模板、更多 KDF/随机工具及跨工具密钥引用。新增依赖前确认跨平台兼容与标准测试向量，不能用算法名称占位冒充支持。当前项目原有 Tab 与存档数量上限未在本批改动。

## 验收

核心测试对照 Node/OpenSSL 密钥解析、签名、PSS 与 DER ECDSA，覆盖错误密钥、不匹配签名、无效报文、OAEP 长度、会话隐私。原生测试验证命名、防覆盖和目录持久化。WebView 支持、Windows ACL 与真实桌面安装仍须平台验收。
